## Projects

### [RubricMate](https://rubric-mate.vercel.app)

Turn an assignment rubric into a checklist you can tick off as you write.

Upload a rubric, write your draft, and see what you have met, what is half done, and what to fix next. Word and source counts run in your browser. The judgement calls go to Claude, with a cheaper or stronger model picked for each check.

`TypeScript` · `Next.js` · `React` · `Tailwind` · `Radix UI` · `Claude API` · `Vercel`
