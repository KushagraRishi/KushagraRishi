<h3 align="center">RubricMate</h3>

<p align="center">
  <b>Turn an assignment rubric into a live checklist while you write.</b>
</p>

<p align="center">
  <a href="https://rubric-mate.vercel.app">
    <img src="https://img.shields.io/badge/Try%20the%20live%20demo-2563EB?style=for-the-badge&logo=vercel&logoColor=white" alt="Try the live demo" />
  </a>
</p>

<p align="center">
  Upload a rubric and draft your assignment.<br />
  RubricMate shows what is complete, what still needs work, and what to fix next.
</p>

<p align="center">
  Simple checks like word count and source count run directly in the browser.<br />
  AI is only used for checks that require understanding the writing.
</p>
